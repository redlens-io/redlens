# Explore and query

Once connected, the **RedLens: Database** view shows your schemas, tables,
views and columns — including external (Spectrum) schemas on Redshift.

- Hover a table and click the **preview** icon to see its first 100 rows.
- Open a `.sql` file, write a query, and press **Ctrl+Enter** to run it.
- Autocomplete suggests schemas, tables, columns and Redshift keywords as you type.
- **RedLens: Query History** reopens any query you have run.
