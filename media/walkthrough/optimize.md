# Optimize like a warehouse engineer

RedLens understands Redshift, not just generic SQL:

- **Explain Query** visualizes the plan and flags redistribution
  (`DS_BCAST`/`DS_DIST`), nested loops and large scans — with concrete
  DISTKEY/SORTKEY fixes.
- **Performance Dashboard** (chart icon in the RedLens view) shows query
  history, table health and an advisor.
- **Explain Plan with AI** / **Optimize Query with AI** use your VS Code
  language model with schema context.
